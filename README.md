# Installation

### Step 1

Install **01cedric COD Updater** and the required **COD files**.

### Step 2

Drag and drop the `MW2_WHITE_WATER` files into your **MW2 mods folder**.

### Step 3

Launch MW2 and start a **Private Match** to use the menu.
